## Безопасность

- Токены ботов **не вшиты в код**: читаются из переменных окружения
  (`BOT_TOKEN`, `DISCORD_TOKEN`). Никогда не выкладывай настоящий токен в репозиторий!
  Токен Discord-бота, который был вшит в исходник, стоит сбросить в Developer Portal.
- В `my-social-profile` телефон и e-mail заменены на заглушки.

## Как выложить на GitHub

Нужен установленный git (или GitHub Desktop):

```
cd github-portfolio
git init
git add .
git commit -m "Portfolio: python/js/html-css projects"
# создать новый репозиторий на github.com, затем:
git branch -M main
git remote add origin https://github.com/<логин>/<имя-репо>.git
git push -u origin main
```

Более простой путь без командной строки — приложение **GitHub Desktop**:
File → Add local repository → выбрать папку → Commit → Publish repository.
