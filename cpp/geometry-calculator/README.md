# Geometry calculator (школьная работа на C++)

Программа на польском: рассчитывает площадь и периметр фигур.
Меню через `switch`: прямоугольник, треугольник (равносторонний), круг, трапеция (равнобедренная).

## Сборка и запуск

```
g++ geometry_calculator.cpp -o geometry
./geometry
```
(В Windows без WSL: `g++ geometry_calculator.cpp -o geometry.exe` — нужен MinGW/MSYS2.)

## Что было исправлено по сравнению с исходной работой

1. `obwTra(a, b, h)` возвращала `a+b+c*2`, где переменная `c` вообще не объявлялась —
   файл просто не компилировался. Теперь боковые стороны равнобедренной трапеции
   считаются по теореме Пифагора: `c = sqrt(((a-b)/2)² + h²)`, периметр = `a + b + 2c`.
2. В `main` переменные объявлялись прямо в `case` без фигурных скобок
   (и `case 4` переобъявлял `a, b`, уже объявленные в `case 1`) — это ошибка C++
   «redeclaration». Каждый `case` обёрнут в свои `{ }`.
