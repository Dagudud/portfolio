# HTML/CSS-работы

Все страницы статические: открывай `index.html` двойным щелчком (или в VS Code — Live Server).

## Готовые страницы

| Папка | Что это |
|---|---|
| `online-newspaper/` | **Многостраничная мини-газета** об игре Resident Evil Requiem: главная + страницы-статьи (`site1-3.html`), фоновые картинки, переходы по ссылкам |
| `personal-blog/` | Личный блог: шапка, меню-ссылки на соцсети, лента постов |
| `games-store/` | Сайт магазина компьютерных игр: каталог карточек с описаниями (RE 4, Metro 2033, God of War…) |
| `coffee-shop/` | Сайт кофейни: витрина-фон, меню напитков с картинками и описаниями |
| `form-styling/` | Страница регистрации и входа: стилизованные поля, чекбоксы согласий |
| `registration-form/` | Форма регистрации + **мини-магазин `my-shop/`** (каталог товаров, отзывы, логотип) |
| `my-social-profile/` | Страница профиля соцсети: фото, цитата, контакты, галерея на второй странице (`images/index2.html`) |
| `news-layout/` | Новостной лейаут: flex-колонки со статьями, меню-шапка |
| `web-dev-collection/` | Лендинг «Team Falcons»: nav, hero-фон, сетка карточек (самая объёмная CSS-работа) |
| `animated-photo-gallery/` | Фотогалерея с CSS-анимациями |
| `css-radio-gallery/` | Галерея на чистом CSS без JavaScript: переключение слайдов через `input[type=radio]` |
| `city-cards/` | Карточки городов с подписями (Minsk, Tokyo, Miami…) |
| `testimonials-page/` | Блок отзывов о курсе: аватарки, подписи авторов |
| `dropdown-menu/` | Выпадающее многоуровневое меню с анимацией |
| `itgenik-site/` | **Многостраничный сайт** про Айтигеника: главная + разделы about (`skills.html`, `album.html`), логотипы на рисунках; стартовая страница — `html/main.html` |
| `semantic-tags-video/` | Учебная страница на семантических тегах (`header/nav/article/aside/footer`) с встроенным `<video>` |

## Практика (упражнения)

`practice/` — отдельные приёмы: `css-selectors/` (селекторы), `page-layout-blocks/` (блочная вёрстка),
`css-grid-basics/` (Grid-система), `elastic-background/` (резиновая вёрстка из фоновых картинок),
`styled-scrollbar/` (кастомный скроллбар), `flexbox-gallery/` (галерея на Flexbox).

## Изменения при сборке

Ссылки со стилем `../Папка/файл`, тянувшие файлы через родительскую папку,
приведены к относительным, чтобы страницы работали в новой структуре репозитория
(содержимое страниц не менялось). В `my-social-profile` личные данные скрыты.
